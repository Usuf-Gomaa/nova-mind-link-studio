# CV project summary

## Nova Mind Link Studio — Full-Stack Dynamic QR Platform

**Tech Stack:** React, TypeScript, Vite, Tailwind CSS, Node.js, Cloudflare Workers, Cloudflare D1 (SQLite), Zod, qr-code-styling, GitHub Actions.

- Built and deployed a company link hub that connects one persistent QR code to an editable, mobile-friendly landing page.
- Developed an Arabic RTL admin dashboard with automatic saving, link ordering and visibility controls, live previews, and branded PNG/SVG QR exports.
- Implemented a serverless API with D1 persistence, HMAC-signed authentication cookies, server-side authorization, input validation, CSRF checks, and login rate limiting.
- Added automated tests for persistence and authentication, TypeScript checks, and CI builds through GitHub Actions.

**GitHub:** https://github.com/Usuf-Gomaa/nova-mind-link-studio
**Live Demo:** https://nova-mind-links.usuf-gomaa.workers.dev/
