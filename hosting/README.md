# النشر على Cloudflare

المشروع يعمل على حساب Cloudflare الخاص بالمالك، بخادم Worker وقاعدة D1. التشغيل المحلي ما زال عبر npm run dev.

- / : صفحة الشركة العامة، وهي وجهة QR.
- /admin : لوحة التحكم؛ تحول الزائر غير المسجل إلى /login.
- /login : تسجيل الدخول بكلمة المرور.

كلمة المرور محفوظة محليًا في .env.hosting.json، وهو ملف مستبعد من Git. لا ترفع هذا الملف أو تشاركه. لتغيير كلمة المرور عدّل ADMIN_PASSWORD في الملف ثم نفّذ أمر secret bulk التالي؛ تغييرها يبطل الجلسات القديمة.

node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js secret bulk .env.hosting.json --config wrangler.json

للنشر التالي: npm run deploy:hosted. الأمر يبني الواجهة ويطبق migrations ويمرر secrets إلى Cloudflare. استيراد البيانات المحلية يحدث فقط إن لم يوجد سجل محفوظ أونلاين؛ إعادة النشر لا تمسح تعديلات الداشبورد.

اختبارات الحماية: npm run test:hosted. تتضمن منع التعديل المجهول، توقيع جلسة الدخول، رفض الجلسات المزورة، منع CSRF، تقييد محاولات الدخول والتحقق من الروابط.

الروابط عامة، وإدارة التعديلات محمية من السيرفر. لا تحتاج أي صلاحيات Cloudflare للوصول إلى صفحة الزوار أو الداشبورد؛ فقط كلمة مرور الداشبورد.

الـQR المحلي القديم يشير إلى عنوان الشبكة المحلية. بعد النشر افتح /admin على عنوان الاستضافة ونزّل QR جديد مرة واحدة لعنوان الإنترنت الثابت. بعد ذلك أي تغيير في الروابط لا يتطلب تغيير QR.
